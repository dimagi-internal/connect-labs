# Sharing a saved run by public link

A public link lets someone without a Labs account open one saved run of a workflow. They see the report as it was when the run was saved, with no sign-in.

## Who can create a link

You need to be Dimagi staff and have access to the run's opportunity or program. If the run holds data from several opportunities, you need access to all of them.

## Create a link

1. Open a saved (completed) run. An in-progress run has no **Share** button.
2. Click **Share**.
3. Choose how long the link lasts: 1, 7, 30 or 90 days, or until a date up to a year away.
4. Read the notice and tick the box.
5. Click **Create link**, then **Copy link**.

## What the person with the link sees

- The report, drawn from a copy of the run made when you created the link. It does not update, and later changes to the workflow do not reach it.
- Anything that needs more than the saved run stays empty: admin boundary shapes on a map, photos, and buttons that do something.

**Anyone with the link can see everything saved in the run**, including worker names and locations, and including data the report does not display. Treat the link as you would the data.

## Ending a link

A link stops working on its end date. To stop it sooner, open **Share** on the run and click **End link**. Deleting the run or its workflow ends its links too.

When a link ends, the copy of the run is deleted from Labs. A record of who shared what, and when, stays, without the report data.

Every view of a link is recorded in the audit trail, as an anonymous visitor.
