{% comment %} The canopy agent panel's launcher ("Ask an agent") on a phone. The launcher is canopy's: a fixed 48px-tall pill, bottom-right, drawn in the widget's shadow root (canopy-web frontend/packages/canopy-widget/src/chrome.ts). Labs cannot change its markup, but the widget exposes it as `part="launcher"` for exactly this: a host restyling its size. At <= 640px the pill sat over the Data page's SQL editor and over the last chart of a workflow run, so there it becomes a 48px round icon button. Its label stays in the button (font-size 0), so it is still the accessible name; the script below also sets it as an aria-label once the panel is ready. Desktop keeps the labelled pill. The pages that pad their end for the launcher (workflow/_agent_launcher_reserve.html, labsdata #ex-page) reserve at least its 48px plus the 16px inset, so the last content still scrolls clear of it. {% endcomment %}
