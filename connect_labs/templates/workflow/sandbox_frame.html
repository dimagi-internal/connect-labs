{% load static %} {% comment %} The sandboxed page frame (workflow/sandbox.py). Deliberately does NOT extend base.html: no CSRF token, no user, no analytics, no navigation. The same bytes for every viewer. Everything a page draws arrives over the bridge from the host page around it (components/workflow/sandbox/). The libraries are the ones the run page loads (workflow/_runner_scripts.html), so render code sees the same globals and classes. {% endcomment %} Page {% comment %} The frame is as tall as its content and never scrolls: the page around it does. The body is moved to the part the person can see (the slice the host's window shows, set by the frame runtime, components/workflow/sandbox/viewport.ts) and its transform makes it the containing block of `position: fixed`, so a dialog is centred where they are looking; the content is moved back by as much, so it stays where it is. The frame also reaches into the page's empty margins either side (host.ts frameGutters); the margins keep the content in its column, and the clip-path clips what overflows it where a box on the page clipped it. {% endcomment %}
