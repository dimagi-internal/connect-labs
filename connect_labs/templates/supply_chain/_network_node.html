The node is the directory row -- slug, Connect user, where, the band set on it, how it is known, Edit -- and, when an item is chosen, `node.stock`: what the point holds (a `network_tree` row). A store's own figures are what is AT it; "with everything below it" sums on hand and what came in from outside the subtree (each unit once, never a hop-summed "issued"). Cover is recomputed for the subtree, never summed. A store that passes stock on (holds nothing itself while the points below it hold some -- `passes_stock_on`) says so in grey: its empty shelf is how it works, not a stock-out. The red alarm stays for points meant to hold stock. {% endcomment %}
