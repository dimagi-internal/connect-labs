{% comment %} expandable_rail_menu: a section's own navigation, drawn as a left rail flush against the Labs sidebar, that slides in and out. Takes `standalone` (true on a full-screen page with no Labs sidebar) and `menu` = {key, title, subtitle, groups: [{label, items: [{label, url, active}]}]}, built by connect_labs.labs.rail_menu.build. base.html includes it for any page a section's menu lists (marketplace/menu.py), so no page template changes to join. The open/closed choice is remembered in this browser (localStorage "railMenu:"). Below 768px the rail is not drawn; the Labs sidebar still reaches every section. Plain CSS rather than utilities, so nothing waits on the stylesheet being rebuilt. The look follows Supply's rail (supply_chain/_rail.html), which this generalises. {% endcomment %}
